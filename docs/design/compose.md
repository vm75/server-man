# Managed containers

Podman Quadlet is the default container backend; Podman Compose is selectable and Docker supports Compose only. Applications edits central YAML through shared validated operations. The former discovered-project tools, native file editors and disabled-marker behavior have been removed. Generated native files are derived outputs.

See [declarative design](declarative.md#initial-compose-adapters) for Compose rendering, ownership, lifecycle, boot integration and current verification limits; [Quadlet](declarative.md#initial-quadlet-adapter) describes the default adapter.
