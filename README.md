# Serverman

A lightweight Linux server manager inspired by Cockpit, with a responsive web interface and MCP access for AI agents. Built with Go, Svelte 5, TypeScript, and Vite.

Implementation has started with the [tracked plan](docs/plans/implementation.md). It covers Compose for Podman and Docker, LXC/LXD, KVM, services, Samba/NFS shares, system updates, and live resource monitoring. Capabilities will be documented here as they become runnable.

The repository lives in this `serverman/` directory because the parent workspace's `.git` mount is read-only.
